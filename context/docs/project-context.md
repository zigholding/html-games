# Project Context

## 当前目标

单文件无限画布拼图可以玩通：上传、打乱、拼接、看原图，拼齐后自动结算。

## 当前状态

`image_puzzle.html` 是唯一实现。原图按钮可以开关预览。

## 已完成

- 上传图片后按难度切块、打乱、在无限画布上拖动拼接
- 吸附合并、双击旋转。拼齐（方向全对且接缝对齐）后自动结算，没有提交按钮
- 顶栏「剩余」= 总块数 − 当前最大一组的块数。打乱会把计时清零，下次拖动再开始计
- 原图预览：`#refToggle` 点击切换 `#refPanel.show`
- 难度只用五颗星，旁边显示块数和行列，例如 `30块 (6×5)`，不显示入门/困难这类档位名。「随机旋转」勾选后，新开局和重新打乱时每块随机为 0° / 90° / 180° / 270°
- 拼齐时播放内嵌的真实掌声（Joseph SARDIN，BigSoundBank #813，CC0，约 5 秒）。刷新恢复已完成的局面时不再播放
- 完成弹层里显示拼好的整图（`state.sessionImg`），刷新后已完成的局面也会带上这张图
- 整局存在 `localStorage` 的 `puzzle-session`。刷新后恢复图片、碎片位置、旋转、分组、计时、星级和随机旋转。cookie 装不下图片和碎片。

## 重要设计决策

### 决策：原图控件不参与舞台拖拽

原因：按钮放在 `#stage` 内。舞台在 `pointerdown` 时 `setPointerCapture`，随后的 `click` 会落到 `#stage`，按钮的监听器不会执行。

影响：`pointerdown`（以及滚轮缩放）遇到 `#refToggle` 或 `#refPanel` 必须直接返回。以后加在舞台上的按钮同样要排除。

## 当前注意事项

- 原图地址在 `startNewGame` 里写成 `state.img` 的 JPEG data URL。没上传图片时面板只有说明文字。
- 「随机旋转」只在开局和打乱时生效，中途勾选不会立刻改当前碎片。旋转用 CSS `transform`，和双击旋转同一套 `p.rot`。
- 上下文与代码冲突时以 `image_puzzle.html` 为准。
