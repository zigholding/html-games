# 无限画布拼图

单文件网页拼图：`image_puzzle.html`。无构建、无依赖，用浏览器直接打开。

## 目标

上传一张图片，切成不规则拼图块，在可平移、缩放的无限画布上拼回原图。

## 结构

- 顶栏：上传、计时、剩余块数、打乱、重切。拼齐后自动弹出完成，没有提交按钮
- 难度：五颗星，1 到 5 档。改难度后若已有图片会重开一局
- `#stage`：画布。`#world` 用 CSS transform 做平移和缩放
- 拼图块是绝对定位的 DOM，图案画在每块自己的 canvas 上

## 交互

- 空白处拖动：平移画布（`pointerdown` 里会对 `#stage` 调用 `setPointerCapture`）
- 拖块：拖整组并尝试吸附。按住 Alt / Shift / Ctrl 只动单块
- 双击：旋转 90°，不弹出还要转多少度的提示
- 难度栏「随机旋转」：开局和打乱时每块随机 0° / 90° / 180° / 270°；未勾选则全部正放
- 双指 / 滚轮：缩放
- `#refToggle` / `#refPanel` 叠在舞台上，用来看原图

## 约束

舞台上的控件不能走平移那条指针捕获路径，否则 `click` 会被重定向到 `#stage`，按钮没有反应。点这些控件时要在 `pointerdown` 里提前返回。

局面存在 `localStorage`（`puzzle-session`），不要改成 cookie：图片和碎片位置超过 cookie 上限，直接打开本地 html 时 cookie 也经常不会保留。
